## 实施内容

### 1. 新增文件

#### `lib/core/services/cache_manager_service.dart`
缓存管理服务统一接口，提供：
- 获取所有缓存项信息
- 获取总缓存大小
- 清理指定类型缓存
- 清理所有缓存
- 格式化文件大小

**关键类**：
- `CacheManagerService` - 主服务类
- `CacheType` - 缓存类型枚举（thumbnail, log, categoryScan）
- `CacheItem` - 缓存项信息模型
- `ClearAllResult` - 批量清理结果模型

#### `test/cache_manager_service_test.dart`
单元测试文件，验证：
- 文件大小格式化
- 缓存类型显示名称
- 缓存项数据模型
- 清理结果模型

**测试结果**：✅ 4/4 通过

### 2. 修改文件

#### `lib/core/logger.dart`
新增日志管理功能：
```dart
Future<int> getLogSize() async;  // 获取日志文件大小
Future<void> clearLogs() async;  // 清理日志文件
```

#### `lib/ui/pages/settings_page.dart`
在"存储管理"部分实现完整的缓存管理UI：

**新增功能**：
1. **缓存管理入口**：`_buildCacheManagementTile()`
2. **缓存管理面板**：`_showCacheManagement()` - 显示所有缓存项
3. **单项清理确认**：`_confirmClearCache()` - 清理前确认
4. **批量清理确认**：`_confirmClearAllCache()` - 全部清理确认
5. **执行清理**：`_performClearCache()` / `_performClearAllCache()`
6. **图标映射**：`_getCacheIcon()` - 为不同缓存类型提供图标

**UI 特性**：
- 可拖拽的底部面板（DraggableScrollableSheet）
- 实时显示缓存大小
- 清理前二次确认
- 清理进度指示器
- 清理结果反馈

## 功能演示流程

### 用户操作流程

1. **进入设置页面**
   - 从主页导航到"设置"
   
2. **查看缓存管理**
   - 点击"存储管理" → "缓存管理"
   - 查看各类缓存的大小和数量

3. **清理单项缓存**
   - 点击某个缓存项的"清理"按钮
   - 确认清理对话框
   - 查看清理结果提示

4. **清理全部缓存**
   - 点击"全部清理"按钮
   - 确认清理对话框
   - 查看清理结果提示

### 缓存项说明

| 缓存类型 | 说明 | 清理影响 |
|---------|------|---------|
| 缩略图缓存 | 视频和音频的预览缩略图 | 下次浏览时需重新生成 |
| 日志文件 | 应用运行日志 | 仅影响开发者调试 |
| 分类扫描缓存 | 文件分类统计数据 | 下次打开分类页面时需重新扫描 |

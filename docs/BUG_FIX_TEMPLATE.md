# Bug 修复模板

## 使用流程

```
遇到 Bug
    ↓
搜索错误库 (ERROR_DATABASE.md)
    ↓
找到匹配？
   ├─ 是 → 应用已知解决方案 → 验证 → 完成
   └─ 否 → 使用本模板系统性排查
           ↓
       发现根本原因
           ↓
       实施修复方案
           ↓
       验证修复
           ↓
       更新错误库
```

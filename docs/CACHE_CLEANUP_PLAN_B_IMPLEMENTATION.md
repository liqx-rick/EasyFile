**清理效果**:

- 释放约5KB空间
- 用户可重新积累搜索历史

**使用场景**:
- ✅ 隐私保护：清除搜索痕迹
- ✅ 数据重置：从头开始积累搜索习惯
- ✅ 空间清理：虽然空间小，但作为隐私数据应提供清理选项

---

### 3.2 视频播放数据清理

**数据存储位置**:
- 存储: SharedPreferences
- 键格式: 
  - `video_position_{videoId}` - 播放进度（毫秒）
  - `video_duration_{videoPath}` - 视频时长（格式化字符串）

**清理内容**:
- 所有视频的播放进度记忆
- 所有视频的时长缓存

**清理实现**:
```dart
// 遍历所有SharedPreferences键
final prefs = await SharedPreferences.getInstance();
final keys = prefs.getKeys();

// 清理所有视频相关键
for (final key in keys) {
  if (key.startsWith('video_position_') || key.startsWith('video_duration_')) {
    await prefs.remove(key);
  }
}
```

**清理效果**:
- 删除所有视频播放进度和时长缓存
- 释放约22KB空间（估算：100个视频 × ~220字节）
- 下次打开视频从头播放
- 时长需要重新读取（首次加载会稍慢）

**使用场景**:
- ✅ 观看重置：重新观看所有视频
- ✅ 隐私保护：清除观看记录
- ✅ 故障排除：解决播放进度记录错误
- ⚠️ 注意：清理后用户需重新定位播放位置

主体信息与声明

易览文件（以下简称"本应用"）由北京光启东方科技有限公司（以下简称"我们"）开发并运营，适用于所有包名为 com.guangqi.easyfile 的渠道版本。

  • 开发者主体：北京光启东方科技有限公司
  • 统一展示名称：北京光启东方科技有限公司

本隐私政策适用于您安装、使用或升级本应用期间发生的个人信息处理活动。

1. 我们如何收集和使用您的个人信息

我们仅在有合法性基础的情形下才会使用您的个人信息。根据适用的法律，我们可能会基于您的同意、为履行/订立您与我们的合同所必需、履行法定义务所必需等合法性基础，使用您的个人信息。 本应用是一款完全本地化的文件管理工具，我们坚持最小化数据收集原则：

  • 本应用自身不收集可直接识别您个人身份的信息
  • 不上传您的文件内容或文件列表
  • 不记录您的具体使用行为
  • 默认不启用账号体系，也不提供云端同步
  • 除依法依规保存的必要日志外，数据均保留在设备本地

注：为统计应用安装量与崩溃情况，本应用集成了友盟+统计 SDK，该 SDK 会采集设备标识符（Android ID、OAID）等信息，具体说明详见第5条。

2. 设备权限调用

本应用在运行过程中需要使用以下权限，我们会在使用之前征求您的意见，任何未明确同意使用的权限，均不会被随意调用。

  • 存储权限：当您使用文件浏览功能时，我们需要调用此权限以便读取和管理设备上的文件和文件夹
  • 照片和视频权限（Android 13+）：当您使用图片/视频分类浏览时，我们需要调用此权限以便访问相应媒体
  • 生物识别权限：当您使用隐私空间功能时，我们需要调用此权限以便提供指纹/面容解锁
  • 查询已安装应用权限：当您使用应用管理功能时，我们需要调用此权限以便展示应用信息
  • 修改系统设置权限：当您使用视频播放器调节亮度时，我们需要调用此权限以便实现亮度控制
  • 应用使用统计权限：当您使用应用管理功能时，我们需要调用此权限以便识别闲置应用
  • APK 安装权限：当您在应用管理中安装 APK 文件时，我们需要调用此权限

您可以随时访问系统"设置"来管理您的系统权限。权限仅用于实现对应功能且在本地执行，我们不会将相关数据分享给未在本政策中说明的第三方。

3. 对未成年人的保护

我们非常重视对未成年人个人信息的保护，将严格按照国家法律法规要求对未成年人提供服务并对未成年人提供保护。如果您是未成年人，需要您的父母或其他监护人同意您使用本应用并同意相关应用的服务条款。父母或其他监护人也应采取适当的预防措施来保护未成年人，包括监督其对本应用的使用。 特别地，如果您是儿童（不满十四周岁的未成年人），在您使用我们的服务前，请务必通知您的父母或其他监护人一起仔细阅读本声明，并在您的父母或其他监护人同意或指导后，使用我们的服务。如果您是儿童的父母或其他监护人，请确保您监护的儿童在您的同意或指导下使用我们的服务。

4. 与第三方共享

为了向您提供完整的服务体验，我们仅在您同意隐私政策后将个人信息提供给第三方 SDK 提供商。为了保障您的数据安全和隐私，我们与合作伙伴签订了数据安全保护协议，明确了合作伙伴对您的数据的保护责任、义务和要求。

  • 共享对象：友盟+统计 SDK 提供商（北京锐讯灵通科技有限公司）
  • 共享信息类型：设备标识符（Android ID、OAID）、设备信息、网络信息、应用运行信息
  • 共享目的：应用安装量统计、活跃用户分析、崩溃堆栈采集
  • 共享方式：通过 HTTPS 加密传输

除上述第三方外，我们不会与其他第三方共享您的个人信息。若未来新增第三方组件，我们会更新本政策并再次征得您的授权。

5. 第三方 SDK 详情

为了向您提供部分功能/服务，我们集成了合作伙伴的软件工具开发包（简称"SDK"）。我们会对 SDK 进行严格的安全检测，并要求合作伙伴采取严格的措施来保护您的个人数据。

  • 【SDK 名称】友盟+ 统计 SDK
  • 【提供方】北京锐讯灵通科技有限公司
  • 【收集的个人信息类型】设备标识符（Android ID、OAID）；设备信息（品牌、型号、系统版本）；网络信息（IP 地址、网络连接类型）；应用运行信息（启动事件、崩溃堆栈）
  • 【使用目的】统计应用安装量、活跃用户数及渠道投放效果；采集崩溃堆栈用于排查与修复应用异常
  • 【使用场景】应用启动时
  • 【收集方式】由友盟+ SDK 在应用启动时自动采集，通过 HTTPS 加密传输至友盟数据服务器
  • 【第三方隐私政策】https://www.umeng.com/policy

请注意，第三方 SDK 可能因为版本升级、策略调整等原因导致数据类型存在一些变化，请以其公示的官方说明为准。

6. 如何保护您的个人信息

我们已使用符合业界标准的安全防护措施保护您提供的个人信息，防止数据遭到未经授权访问、公开披露、使用、修改、损坏或丢失。

  • 【安全防护措施】应用设置和隐私空间采用加密方式保存；传输数据使用 HTTPS 加密传输；遵循最小权限原则实施访问控制
  • 【数据保留期限】用户本地数据保留至应用卸载；SDK 数据由第三方按其政策保留；法律法规另有规定的情况除外
  • 【安全事件处理】如若发生个人信息安全事件，我们将按照法律法规的要求及时向您告知，并采取补救措施

我们持续投入资源提升数据与隐私安全防护能力。

7. 管理您的个人信息

我们非常尊重您对个人信息的关注，并为您提供了以下数据主体权利及选择：

  • 【信息访问】您可以前往"关于"页面查看应用信息，所有个人数据均存储在本地设备中
  • 【信息更正】当您需要更新个人信息时，您可以前往"设置"修改相关配置
  • 【信息删除】您可以前往"设置 > 清除缓存"删除缓存数据，或前往"隐私空间"清空加密文件，或直接卸载应用删除全部本地数据
  • 【撤销同意】您可以在系统"设置 > 应用管理 > 易览文件 > 权限"中随时撤销已授予的权限
  • 【注销服务】本应用当前版本不提供账号注册功能，直接卸载应用即可删除全部数据

如您对您的数据主体权利有进一步要求或存在任何疑问、意见或建议，可通过本声明最后"如何联系我们"章节所述方式与我们取得联系，并行使您的相关权利。

8. 信息存储地点及期限

我们承诺，除法律法规另有规定外，我们对您的信息的保存期限应当为实现处理目的所必要的最短时间。

  • 【本地存储】文件浏览记录、应用设置、收藏等信息存储在您的设备本地，保留至您主动删除或卸载应用
  • 【隐私空间数据】加密文件和 PIN 码采用加密方式保存在设备本地，保留至您主动清空或卸载应用
  • 【SDK 数据】友盟 SDK 采集的统计数据传输并保存至中国境内的友盟服务器，按其隐私政策保留

我们不会主动将您的设备本地数据备份到云端或传输到中国境外的服务器。

9. 隐私政策变更

我们可能会根据业务发展或法律法规更新本政策。重大变更（如第三方 SDK 调整、信息收集目的改变等）会通过弹窗、站内提示或版本更新说明通知您。继续使用本应用即表示您接受更新后的政策。

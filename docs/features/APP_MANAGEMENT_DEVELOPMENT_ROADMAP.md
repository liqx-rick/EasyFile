#### 功能 2.3: 应用缓存清理 ⬜
**预计时间**: 1周  
**优先级**: P0

**技术难点**:
- 需要系统级权限或root
- 可能需要引导用户手动清理
- 或使用AccessibilityService自动化

**技术方案（方案A - 引导清理）**:
```dart
// 跳转到应用详情页面，引导用户点击"清除缓存"
await SystemIntentService.openAppSettings(packageName);
// 显示操作指引overlay
showCleanCacheGuide();
```

**技术方案（方案B - 批量清理）**:
```dart
// 使用pm命令（需要root或系统权限）
await Process.run('pm', ['clear-cache', packageName]);
```

**实现步骤**:
1. 研究可行的清理方案
2. 选择最佳方案实现
3. 实现批量清理流程
4. 添加清理结果反馈
5. 测试清理效果

#### 功能 2.4: 应用推荐引擎 ⬜
**预计时间**: 1周  
**优先级**: P1

**推荐策略**:
1. **大缓存应用**: 缓存 > 100MB
2. **长时间未使用**: 30天以上未打开
3. **存储占用大**: 总占用 > 500MB
4. **多个旧版本APK**: 检测到安装包残留

**实现步骤**:
1. 设计推荐算法
2. 实现应用评分机制
3. 创建推荐列表UI
4. 添加"一键清理推荐"
5. 测试推荐准确度

**数据结构**:
```dart
class AppRecommendation {
  final EasyFileAppInfo app;
  final RecommendationType type;
  final int score; // 0-100
  final String reason;
  final int potentialSaving; // bytes
}

enum RecommendationType {
  largeCache,      // 大缓存
  longUnused,      // 长期未用
  largeSize,       // 占用大
  multipleApks,    // 多个APK
}
```

# 📱 存储管理功能详细设计方案 (方案D)

## 🎯 方案概述

将browse Tab的快速访问区现有的单个存储卡片拆分为两个独立功能卡片:
- **文件浏览卡片**: 保留原StoragePage的文件浏览功能
- **存储管理卡片**: 新增存储管理功能入口(缓存清理+存储分析)

## 🎴 卡片详细设计

### 2️⃣ 文件浏览卡片 (FilesBrowseCard)

#### 功能定位
- 原有存储信息卡片的重命名和简化版本
- 职责: 显示存储空间使用情况,提供存储根目录浏览入口

#### 卡片结构
```
┌────────────────────────┐
│ 📁 文件浏览             │ <- 标题行 (图标+文字)
│                        │
│ ━━━━━━━━━━━━━━ 75%    │ <- 进度条 (根据使用率变色)
│                        │
│ 已用 15.2GB / 20GB     │ <- 存储使用情况
│                        │
│                        │
│ [浏览存储空间]          │ <- 操作按钮
└────────────────────────┘
```

#### 交互行为
| 操作 | 行为 |
|-----|------|
| **点击卡片** | 跳转到StoragePage(存储根目录文件浏览) |
| **点击[浏览存储空间]按钮** | 同上,跳转到StoragePage |
| **长按卡片** | (可选)显示快捷菜单: 浏览存储/查看详情/设置 |

#### 数据来源
- **存储空间信息**: 通过`disk_space_plus`插件获取(已有)
  - 总容量: `totalSpace`
  - 已用空间: `totalSpace - freeSpace`
  - 使用率: `(totalSpace - freeSpace) / totalSpace * 100%`

#### 视觉设计
- **卡片尺寸**: 
  - 宽度: (容器宽度 - 8px间距) / 2 (大屏幕并排)
  - 高度: 与分类卡片高度一致 (约100-120dp)
  - 圆角: 12px
  - 内边距: 12px
- **进度条颜色**:
  - <60%: 绿色 (#4CAF50)
  - 60%-80%: 橙色 (#FF9800)
  - >80%: 红色 (#F44336)
- **按钮样式**:
  - 文字按钮,无边框
  - 颜色: 主题色 (Theme.primaryColor)
  - 字体大小: 14sp

### 3️⃣ 存储管理卡片 (StorageManagementCard)

#### 功能定位
- 全新的存储管理功能入口
- 职责: 显示可清理的缓存大小,提供存储管理页面入口

#### 卡片结构
```
┌────────────────────────┐
│ 🗂️ 存储管理   [NEW]    │ <- 标题行 (图标+文字+角标)
│                        │
│  缓存清理              │ <- 副标题
│  1.2GB 可清理          │ <- 可清理缓存大小
│                        │
│  ┌────────────┐       │
│  │   [管理]    │       │ <- 操作按钮 (突出显示)
│  └────────────┘       │
└────────────────────────┘
```

#### 交互行为
| 操作 | 行为 |
|-----|------|
| **点击卡片** | 跳转到StorageManagementPage(存储管理页面) |
| **点击[管理]按钮** | 同上,跳转到StorageManagementPage |
| **长按卡片** | (可选)显示快捷菜单: 存储管理/清理所有缓存 |

#### 数据来源
- **缓存大小计算**: 遍历所有缓存类型,累加大小
  - 缩略图缓存: `CacheManagerService.getThumbnailCacheSize()`
  - 日志文件: `Logger.getLogSize()`
  - 扫描缓存: `CacheManagerService.getCategoryScanCacheSize()`
  - 搜索历史: `SearchHistoryService.getHistorySize()`
  - 视频播放数据: `CacheManagerService.getVideoPlaybackCacheSize()`

#### 视觉设计
- **卡片尺寸**: 
  - 宽度: 与文件浏览卡片相同
  - 高度: 与文件浏览卡片相同
  - 圆角: 12px
  - 内边距: 12px
- **"NEW"角标**:
  - 位置: 右上角
  - 背景色: 主题色 (#2196F3)
  - 文字颜色: 白色
  - 字体大小: 10sp
  - 显示逻辑: 首次显示后7天内可见
- **[管理]按钮样式**:
  - 填充按钮,有背景色
  - 背景色: 主题色 (Theme.primaryColor)
  - 文字颜色: 白色
  - 字体大小: 14sp
  - 内边距: 12px横向, 8px纵向
  - 圆角: 8px

### 6️⃣ 存储空间概览区

#### 功能设计
- 显示存储总容量和已用空间
- 显示存储使用进度条(根据使用率变色)
- 按文件类型统计占用空间(图片/视频/文档/音乐/其他)
- 每种文件类型显示占用大小和可视化进度条

#### 数据来源
- **总容量和已用空间**: `disk_space_plus`插件
- **分类占用统计**: 需要新增扫描功能
  - 图片: 扫描CategoryType.images对应的所有文件
  - 视频: 扫描CategoryType.video对应的所有文件
  - 文档: 扫描CategoryType.documents对应的所有文件
  - 音乐: 扫描CategoryType.music对应的所有文件
  - 其他: 总已用空间 - 以上四类总和

#### 交互行为
| 操作 | 行为 |
|-----|------|
| **点击分类条目** | (未来功能)跳转到该分类的文件列表,按大小排序 |
| **长按分类条目** | (未来功能)显示该分类的详细统计信息 |

#### 视觉设计
- **进度条颜色**: 与文件浏览卡片一致
  - <60%: 绿色 (#4CAF50)
  - 60%-80%: 橙色 (#FF9800)
  - >80%: 红色 (#F44336)
- **分类进度条**: 使用主题色的不同透明度
- **卡片样式**:
  - 背景色: Surface color
  - 圆角: 12px
  - 内边距: 16px
  - 阴影: elevation = 1

### 7️⃣ 缓存管理区

#### 功能设计
- 列表显示5种缓存类型
- 每种缓存显示: 名称/描述/占用大小/清理按钮
- 支持单独清理每种缓存
- 支持一键清理所有缓存
- 清理后实时更新占用大小

#### 缓存类型详细说明

| 缓存类型 | 图标 | 名称 | 描述 | 数据来源 |
|---------|-----|------|-----|---------|
| **缩略图** | 🖼️ | 缩略图缓存 | 系统生成的文件缩略图预览 | `getThumbnailCacheSize()` |
| **日志** | 📝 | 日志文件 | 应用运行日志和错误记录 | `getLogSize()` |
| **扫描** | 🔍 | 分类扫描缓存 | 文件分类扫描的临时数据 | `getCategoryScanCacheSize()` |
| **搜索** | 📋 | 搜索历史记录 | 文件搜索的历史记录数据 | `getHistorySize()` |
| **视频** | 🎬 | 视频播放数据 | 视频播放进度和播放记录 | `getVideoPlaybackCacheSize()` |

#### 交互行为

| 操作 | 行为 |
|-----|------|
| **点击[清理]按钮** | 弹出确认对话框 → 确认后清理该缓存 → 显示清理结果 → 更新大小 |
| **点击[清理全部缓存]** | 弹出确认对话框 → 确认后清理所有缓存 → 显示清理结果 → 更新所有大小 |
| **点击缓存条目** | 展开显示该缓存的详细信息(路径/文件数量等) |

#### 清理确认对话框设计


## 🔄 交互流程设计

### 9️⃣ 用户流程1: 查看存储使用情况

```
1. 用户打开EasyFile → browse Tab
2. 向下滚动到快速访问区
3. 看到"📁 文件浏览"卡片,显示"已用 15.2GB/20GB"
4. 用户了解当前存储使用情况
```

**所需步骤**: 2步
**当前方案**: 3步(切换Tab → 滚动 → 查看)

### 🔟 用户流程2: 清理缓存释放空间

```
1. 用户打开EasyFile → browse Tab
2. 向下滚动到快速访问区
3. 看到"🗂️ 存储管理"卡片,显示"1.2GB 可清理"
4. 点击卡片或[管理]按钮
5. 进入存储管理页面,看到所有缓存类型和大小
6. 点击某个[清理]按钮或[清理全部缓存]
7. 弹出确认对话框,点击[清理]
8. 显示清理结果,看到缓存大小变为0B
```

**所需步骤**: 4步(切换Tab → 点击卡片 → 点击清理 → 确认)
**当前方案**: 5步(右上角菜单 → 设置 → 滚动 → 缓存管理 → 清理)
**优化**: 减少1步,流程更清晰

# 文件显示功能测试用例

## 测试环境准备

### 1. 创建测试文件和文件夹结构

在 Android 设备的 `/storage/emulated/0/EasyFileTest/` 目录下创建以下结构：

```
EasyFileTest/
├── 正常文件.txt
├── .隐藏文件.txt                    [隐藏文件]
├── .gitignore                       [隐藏文件]
├── thumbs.db                        [系统文件]
├── .nomedia                         [系统文件]
├── 正常文件夹/
│   ├── 文档1.pdf
│   └── 文档2.doc
├── .隐藏文件夹/                     [隐藏文件夹]
│   ├── 隐藏内容1.txt
│   └── 隐藏内容2.jpg
├── Android/                         [系统文件夹]
│   └── data/
├── .thumbnails/                     [系统文件夹]
│   └── cache.db
└── lost+found/                      [系统文件夹]
```

### 2. 使用 ADB 创建测试文件

```bash
# 创建测试目录
adb shell mkdir -p /storage/emulated/0/EasyFileTest

# 创建正常文件
adb shell "echo 'Normal file' > /storage/emulated/0/EasyFileTest/正常文件.txt"

# 创建隐藏文件
adb shell "echo 'Hidden file' > /storage/emulated/0/EasyFileTest/.隐藏文件.txt"
adb shell "echo '*.log' > /storage/emulated/0/EasyFileTest/.gitignore"

# 创建系统文件
adb shell "touch /storage/emulated/0/EasyFileTest/thumbs.db"
adb shell "touch /storage/emulated/0/EasyFileTest/.nomedia"

# 创建正常文件夹
adb shell mkdir -p /storage/emulated/0/EasyFileTest/正常文件夹
adb shell "echo 'Doc1' > /storage/emulated/0/EasyFileTest/正常文件夹/文档1.pdf"

# 创建隐藏文件夹
adb shell mkdir -p /storage/emulated/0/EasyFileTest/.隐藏文件夹
adb shell "echo 'Hidden content' > /storage/emulated/0/EasyFileTest/.隐藏文件夹/隐藏内容1.txt"

# 创建系统文件夹
adb shell mkdir -p /storage/emulated/0/EasyFileTest/Android/data
adb shell mkdir -p /storage/emulated/0/EasyFileTest/.thumbnails
adb shell mkdir -p /storage/emulated/0/EasyFileTest/lost+found
```

## 测试用例

### 测试用例 1: 显示隐藏文件功能 - 基础测试

**目的：** 验证显示/隐藏隐藏文件开关的基本功能

**前置条件：**
- 测试文件夹包含隐藏文件和正常文件
- 显示隐藏文件开关默认关闭

**测试步骤：**
1. 打开应用，进入文件浏览器
2. 导航到 `/storage/emulated/0/EasyFileTest/`
3. 记录当前显示的文件列表
4. 进入设置页面
5. 找到"文件管理"分组
6. 打开"显示隐藏文件"开关
7. 返回文件浏览器（需要刷新）
8. 再次查看文件列表

**预期结果：**
- 步骤3：应该只看到正常文件（`正常文件.txt`、`正常文件夹/`）
- 步骤8：应该看到所有文件，包括隐藏文件（`.隐藏文件.txt`、`.gitignore`、`.隐藏文件夹/`）

---

### 测试用例 2: 显示隐藏文件功能 - 关闭测试

**目的：** 验证关闭显示隐藏文件后，隐藏文件正确消失

**前置条件：**
- "显示隐藏文件"开关已打开
- 当前可以看到隐藏文件

**测试步骤：**
1. 在文件列表中确认可以看到隐藏文件
2. 进入设置页面
3. 关闭"显示隐藏文件"开关
4. 返回文件浏览器
5. 查看文件列表

**预期结果：**
- 隐藏文件应该消失
- 只显示正常文件

---

### 测试用例 4: 系统文件过滤 - 文件级别

**目的：** 验证系统文件（如 thumbs.db）的过滤

**前置条件：**
- 测试文件夹包含系统文件
- 显示系统文件开关关闭

**测试步骤：**
1. 导航到测试文件夹
2. 查看文件列表，确认不显示 `thumbs.db` 和 `.nomedia`
3. 打开"显示系统文件"开关
4. 返回文件列表
5. 确认现在可以看到系统文件

**预期结果：**
- 步骤2：`thumbs.db` 和 `.nomedia` 不可见
- 步骤5：`thumbs.db` 和 `.nomedia` 可见

---

### 测试用例 5: 组合测试 - 同时控制两个开关

**目的：** 验证两个开关可以独立工作且互不干扰

**测试步骤：**

**场景 A：两个开关都关闭（默认）**
1. 确保两个开关都关闭
2. 查看文件列表
3. 预期：只显示正常文件和文件夹

**场景 B：只打开显示隐藏文件**
1. 打开"显示隐藏文件"
2. 关闭"显示系统文件"
3. 查看文件列表
4. 预期：显示正常文件 + 隐藏文件（`.xxx`），但不显示系统文件夹（`Android`等）

**场景 C：只打开显示系统文件**
1. 关闭"显示隐藏文件"
2. 打开"显示系统文件"
3. 查看文件列表
4. 预期：显示正常文件 + 系统文件/文件夹，但不显示隐藏文件（`.xxx`）

**场景 D：两个开关都打开**
1. 打开"显示隐藏文件"
2. 打开"显示系统文件"
3. 查看文件列表
4. 预期：显示所有文件和文件夹

**预期结果：**
- 四种组合都能正常工作
- 两个开关互不影响

### 测试用例 6: 设置持久化测试

**目的：** 验证设置在应用重启后是否保留

**测试步骤：**
1. 打开"显示隐藏文件"和"显示系统文件"
2. 完全关闭应用（从最近任务中划掉）
3. 重新打开应用
4. 进入设置页面
5. 检查两个开关的状态
6. 进入文件浏览器
7. 验证隐藏文件和系统文件是否显示

**预期结果：**
- 步骤5：两个开关应该保持打开状态
- 步骤7：隐藏文件和系统文件应该都可见

### 测试用例 8: 边界情况测试

**目的：** 测试特殊情况下的行为

**测试内容：**

**8.1 空文件夹**
- 在只包含隐藏文件的文件夹中关闭显示隐藏文件
- 预期：显示空文件夹提示

**8.2 根目录**
- 在 `/storage/emulated/0/` 根目录测试
- 预期：`Android/` 文件夹应该可以被过滤

**8.3 嵌套隐藏文件夹**
- 进入隐藏文件夹内部（`.隐藏文件夹/`）
- 关闭显示隐藏文件开关
- 预期：可能有两种行为，需要决定：
  - A. 当前在隐藏文件夹内，继续显示内容
  - B. 自动退出到父文件夹

**8.4 文件名特殊字符**
- 创建名为 `.` 或 `..` 的文件（如果允许）
- 验证过滤行为

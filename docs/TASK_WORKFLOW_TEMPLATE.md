# 任务执行标准流程模板

> **目的**：确保开发过程中每个任务都经过充分的设计确认、实施验证和测试验收，避免返工和误解。

---

## 📋 流程总览

```
阶段1: 任务启动确认 → 阶段2: 功能设计确认 → 阶段3: 实施 → 阶段4: 测试验收 → 阶段5: 任务关闭
```

## 🎮 快捷关键词（触发器）

在对话中使用以下关键词可以快速触发对应阶段：

| 关键词 | 触发效果 | 适用阶段 |
|--------|---------|---------|
| `【设计确认】Task X` | Agent 输出详细设计方案 | 阶段1→2 |
| `【开始实施】` | Agent 开始编码，不再询问 | 阶段2→3 |
| `【测试就绪】` | Agent 输出测试用例清单 | 阶段3→4 |
| `【验收通过】` | Agent 关闭任务，询问下一步 | 阶段4→5 |
| `【发现问题】XXX` | Agent 进入Bug修复模式 | 阶段4循环 |
| `【继续】` | Agent 继续当前阶段工作 | 任意阶段 |
| `【暂停】` | Agent 保存当前进度，等待恢复 | 任意阶段 |

## 💡 使用建议

### 对于 User：
1. **开始任务时**：直接说 `【设计确认】Task X`，让 Agent 输出设计方案
2. **确认设计后**：说 `【开始实施】`，Agent 会立即开始编码
3. **测试时**：按照 Agent 提供的测试场景逐一验证
4. **发现问题**：说 `【发现问题】[具体描述]`，Agent 会立即修复
5. **验收通过**：说 `【验收通过】`，Agent 会关闭任务并询问下一步

### 对于 Agent：
1. **严格按照5个阶段执行**，不跳步骤
2. **每个阶段等待 User 明确反馈**后才进入下一阶段
3. **设计方案要详细**：包括技术方案、UI效果、涉及文件
4. **测试用例要完整**：包括正常流程、边界情况、回归测试
5. **发现问题立即修复**：不要积累问题到最后

# 快速访问管理说明文档（基于代码实现分析）

## 1. 功能概述

“快速访问”模块用于管理和展示用户常用的文件夹入口，提升文件浏览效率。其核心包括：
- 智能检测常用/重要文件夹（如系统目录、应用目录、用户自建目录）。
- 支持用户自定义加入/移除/隐藏/重命名快速访问项。
- 在主页“快速访问”区块和菜单中高效展示。

## 2. 主要数据结构

### QuickAccessFolder
- `id`：唯一标识
- `path`：文件夹路径
- `originalName`：原始文件夹名
- `userAlias`/`recommendedAlias`：用户自定义/系统推荐别名
- `type`：system（系统目录）/other（其他目录）
- `isAddedToQuickAccess`：是否已加入快速访问
- `isHidden`：是否被隐藏
- `parentPath`：父目录路径（支持二级目录）

## 3. 快速访问管理页面逻辑

- 页面分为“常用文件夹区”（系统目录）和“其他文件夹区”（应用/自建目录）。
- 支持对每个文件夹进行：
  - 加入/移除快速访问
  - 隐藏（不再显示）
  - 编辑别名
- 支持刷新/重新扫描，自动检测新文件夹。
- 支持二级目录展开（系统目录下的子文件夹）。

## 4. 文件夹检测与管理核心流程

### 4.1 检测逻辑（QuickAccessFolderDetector）
- 扫描系统常用目录（如Download、DCIM、Pictures等）及其一级子目录。
- 扫描根目录下满足条件的其他用户文件夹。
- 检测条件（任一满足即可）：
  - 包含重要文档（如PDF/Office/大图片/视频）
  - 文件数≥5
  - 文件夹大小≥5MB
  - 文件类型多样性≥2
- 黑名单目录（如.cache、node_modules等）自动跳过。

### 4.2 数据持久化（QuickAccessLocalSource）
- 检测到的文件夹信息持久化为JSON文件。
- 支持批量加入/移除/隐藏/重命名等操作，所有变更实时保存。

### 4.3 业务处理（QuickAccessPresenter）
- 负责加载、刷新、批量操作、别名设置等业务逻辑。
- 所有操作均通过ViewModel驱动UI自动刷新。

## 5. 主页-快速访问菜单显示逻辑

- 主页“快速访问”区块（QuickAccessSection）和菜单，均通过ViewModel获取当前所有`isAddedToQuickAccess==true && isHidden==false`的文件夹。
- 展示顺序：
  - 系统目录优先，按预设顺序排列
  - 其他目录按名称排序
- 支持二级目录（系统目录下的子文件夹）展开/收起
- 用户可通过菜单快速跳转到对应文件夹
- 用户自定义别名优先显示

## 6. 典型操作说明

- **加入快速访问**：在管理页或扫描结果中点击“加入”，文件夹`isAddedToQuickAccess`设为true，立即在主页区块/菜单显示。
- **移除快速访问**：点击“移除”，`isAddedToQuickAccess`设为false，主页区块/菜单不再显示，但数据保留。
- **隐藏**：点击“忽略”，`isHidden`设为true，所有界面不再显示，可通过重新扫描恢复。
- **重命名**：编辑别名后，优先显示用户自定义别名。

## 7. 其他说明

- 所有操作均不影响实际文件，仅影响入口显示。
- 支持批量操作和状态同步，保证高性能和一致性。
- 支持多端/多会话下的数据一致性（基于本地持久化）。

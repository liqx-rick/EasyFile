## 应用介绍正文

易览文件 - 更懂你需求的智能文件管家

易览文件是一款集智能助手、文件管理、专业工具于一体的全功能文件管理应用。采用独创三屏智能架构，通过主动任务推荐、精细文件管理、场景化工具集三大核心能力，帮助用户高效管理手机中的每一份文件与空间。

▊ 三屏智能交互，各司其职

**智能助手屏（左滑进入）** - 你的主动管家
自动扫描设备文件状况，智能推送清理建议：
 - 智能任务卡：自动发现重复文件、大文件、应用缓存等优化机会
 - 空间健康监测：实时显示存储状态，空间紧张时主动提醒
 - 快速操作入口：一键直达大文件、重复文件、系统回收站、新文件页面
 - 最近活动追踪：清理成果可视化，手机瘦身一目了然

**文件管理屏（中间主页）** - 专业浏览能力
全面的文件浏览与管理中心：
 - 多视图模式：最近文件、分类浏览、收藏管理、新文件追踪、应用管理
 - 智能分类：按图片、视频、音频、文档、安装包、压缩包等12+类型自动归类
 - 文件搜索：支持文件名快速搜索，精准定位目标文件
 - 快捷访问区：回收站、垃圾清理、压缩包管理、应用管理等常用功能快速入口

**专业工具屏（右滑进入）** - 场景化工具集
按使用场景分组的深度工具箱：
 • 存储优化工具（6项）
   - 大文件分析：查找超大文件，释放存储空间
   - 重复文件清理：智能识别相同文件，一键批量删除
   - 垃圾清理：扫描临时文件、空文件夹、APK残留等系统垃圾
   - 安装包管理：集中管理APK文件，清理已安装应用的安装包
   - 应用管理：查看应用占用、跳转系统设置清理缓存
   - 系统回收站：管理系统回收站文件，彻底释放空间

 • 安全与隐私工具（1项）
   - 隐私空间：PIN码或生物识别加密保护私密文件

 • 实用小工具（4项）
   - Hash校验：支持MD5/SHA-1/SHA-256文件完整性验证
   - 文件夹大小计算器：快速统计文件夹占用空间
   - 文件类型识别器：通过文件头识别真实文件格式
   - 二维码工具：扫描与生成二维码，支持文本、链接等内容

▊ 文件预览与深度处理

**多格式预览体验**
 - 图片浏览：支持沉浸式全屏查看，手势缩放
 - 视频播放：内置播放器，支持主流视频格式
 - PDF阅读：支持多页PDF文档浏览与缩放
 - 音频播放：后台播放支持，适合听书、听音乐
 - 文本查看：支持TXT等文本文件快速预览

**压缩包深度支持**
 - 格式兼容：支持ZIP、7Z、RAR等常见压缩格式
 - 压缩包内容预览：无需解压即可浏览内部文件列表
 - 文件解压：支持全部解压或选择性解压指定文件
 - 解压记录：自动记录解压历史，方便再次访问

▊ 智能清理与存储优化

**重复文件智能检测**
 - 内容级别检测：通过文件哈希值识别完全相同的文件
 - 分组展示：按相似度分组，清晰显示可节省空间
 - 智能推荐：自动保留最优文件（最新、路径优先等）
 - 安全清理：预览确认后删除，避免误删

**垃圾文件深度扫描**
 - 多类型覆盖：临时文件、空文件夹、日志文件、已安装APK等
 - 大小排序：优先显示占用空间大的垃圾项
 - 自定义清理：用户可自主选择清理类别
 - 一键清理：批量删除，快速释放空间

**存储空间可视化**
 - 分类占用统计：按文件类型显示存储占用比例
 - 应用占用分析：查看各应用的存储使用情况
 - 剩余空间监控：实时显示可用存储，空间告急时预警

▊ 隐私保护与安全管理

**隐私空间独立加密**
 - 多重验证：支持PIN码、指纹、面容识别等方式
 - 独立存储：私密文件单独存放，主界面不可见
 - 会话管理：退出后自动锁定，保护隐私安全
 - 灵活操作：支持移入、移出、删除等完整文件管理

**隐私合规承诺**
 - 首次启动明确展示隐私政策，用户同意后再启用功能
 - 权限请求透明化，仅在必要时申请，说明使用目的
 - 数据本地处理，文件扫描与管理均在本地完成
 - 第三方SDK（友盟统计）数据采集范围明确告知

▊ 应用回收站安全机制

**误删保护**
 - 删除文件不直接清空，先进入应用回收站
 - 回收站支持还原与永久删除双重操作
 - 自动清理机制：可设置回收站文件保留时长
 - 空间统计：显示回收站占用，支持一键清空

▊ 适用场景与人群

**日常文件管理**
 - 整理手机相册、下载文件、微信文件等
 - 管理视频、音乐、文档等多媒体资源
 - 查找最近产生的文件或收藏的重要文件

**存储空间优化**
 - 手机提示空间不足时快速清理
 - 定期清理重复照片、无用视频
 - 删除已安装应用的APK安装包

**文件专业处理**
 - 开发者验证APK文件的Hash值
 - 快速统计项目文件夹占用大小
 - 识别文件真实格式，避免格式欺诈

**隐私文件保护**
 - 保护私人照片、敏感文档
 - 加密存储重要合同、证件扫描件
 - 防止他人翻看手机时泄露隐私

▊ 技术亮点

 - Flutter跨平台架构，Material Design风格界面
 - 原生C/C++压缩算法集成，高性能解压体验
 - 多级缓存策略，扫描结果持久化，避免重复扫描
 - 增量更新机制，仅扫描变化文件，节省性能
 - 异步并发处理，大数据量场景下依然流畅

▊ 为什么选择易览文件

与传统文件管理器的被动浏览不同，易览文件通过智能助手主动发现手机文件问题，推送优化建议，让用户"有事可做"而非"不知道做什么"。三屏架构将浏览、清理、工具分离，各司其职，降低使用门槛的同时提供深度专业能力。

无论是日常文件查找，还是存储空间紧急清理，或是压缩包处理、隐私保护等专业需求，易览文件都能提供清晰、高效、安全的解决方案。

易览文件，让文件管理更智能、更简单、更安心。

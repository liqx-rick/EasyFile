# 已知限制 (Known Limitations)

本文档记录EasyFile应用中已知的技术限制和平台限制。

## Android生物识别方向锁定限制

### 问题描述
当用户使用生物识别（指纹/面部识别）进入隐私空间时，如果设备处于横屏模式，验证完成后屏幕会被锁定在竖屏模式，无法自动切换回横屏。

### 根本原因
这是Android系统`BiometricPrompt` API的限制：
- `BiometricPrompt`对话框会强制设备进入竖屏模式
- 对话框关闭后，这个方向锁定会在当前Activity中持续存在
- Flutter的`SystemChrome.setPreferredOrientations()` API无法立即解除这个系统级的方向锁定
- 只有通过页面导航（push/pop）触发Activity重新布局，才能让方向设置重新生效

### 技术细节
已尝试的解决方案（均无效）：
1. ✗ 生物识别完成后立即调用方向恢复API
2. ✗ 增加100ms/300ms延迟后再调用方向恢复API
3. ✗ 在目标页面的`initState()`中再次调用方向恢复API
4. ✗ 延迟1秒后再调用方向恢复API

代码执行日志显示所有API调用都成功执行，但Android系统忽略了这些设置。

### 临时解决方案
用户可以通过以下操作手动触发横屏恢复：
1. 生物识别验证后进入隐私空间（此时锁定在竖屏）
2. 打开任意子页面，例如：
   - 点击"添加文件"按钮打开文件选择对话框
   - 点击设置按钮进入隐私设置页面
3. 按系统返回键返回隐私空间主页面
4. 此时横屏显示恢复正常

### 影响范围
- 仅影响使用生物识别验证的场景
- 使用PIN码验证不受影响（因为PIN输入页面是Flutter实现，不涉及系统对话框）
- 用户可以通过简单的交互操作恢复横屏显示

### 长期解决方案探索
可能的解决方向（需要进一步研究）：
1. 使用Android原生代码通过`Activity.setRequestedOrientation()`直接控制方向
2. 实现自定义的生物识别UI（不使用系统BiometricPrompt）
3. 在生物识别完成后，通过原生代码强制触发Activity配置变化

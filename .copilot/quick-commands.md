# GitHub Copilot 快速指令手册

复制以下指令，修改 `[占位符]` 部分，直接发送给 Copilot 即可。

---

## 🚀 功能开发

### 新增功能（标准流程）
```

```

- `请用模板A实现 文件批量重命名 功能`

## 📌 常用占位符说明

- `[功能描述]` - 要实现的功能名称（如：文件加密、云同步）
- `[模块/功能]` - 要优化的模块（如：图片加载、数据库查询）
- `[Bug描述]` - Bug的具体表现（如：应用崩溃、数据丢失）
- `[改动描述]` - 小改动内容（如：修改颜色、调整尺寸）
- `[分支名称]` - Git分支名（如：cloud-sync、optimize-startup）
- `[版本号]` - 版本号（如：2.0.0、2.1.0）
- `[文件/模块]` - 具体的文件或模块名
- `[内容描述]` - 文档内容说明

---

## 🚨 注意事项

1. **模板组合**：可以自由组合多个模板（如：G1 + A + G2）
2. **等待确认**：模板A/B/C会在关键步骤等待你确认
3. **快速模式**：模板D适合小改动，会直接提交
4. **分支管理**：使用G系列模板管理Git分支操作
